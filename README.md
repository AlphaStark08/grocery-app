# QuickBasket 🛒

A full-stack grocery delivery web application built using React, Node.js, and Express.

## Features
- User Authentication (Login/Signup)
- Cart Management
- Category Filtering
- Search Functionality
- Real-time Users (Socket.IO)
- Checkout System

## Tech Stack
- Frontend: React.js
- Backend: Node.js + Express
- Real-time: Socket.IO
- Storage: JSON File

## How to Run
1. Start backend
   node server.js

2. Start frontend
   npm start
